HANDOVER.md

Convention for every agent working with this HANDOVER.md:

Instructions for the start of a session can be found under ## Shift Handoff in AGENTS.md.

At the end of a session, carefully read the instructions under ## Shift Handoff in AGENTS.md and use the template under ## Template for a HANDOVER.md-Entry in AGENTS.md to create a new entry in this file.

Important: Do not delete old entries, because they represent the history, like a git log, but in narrative form. If the file becomes too long, move the oldest entries to HANDOVER_ARCHIVE.md (once there are more than 50 entries).
