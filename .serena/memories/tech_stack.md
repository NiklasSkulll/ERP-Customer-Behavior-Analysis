# Environment and tooling
- WSL/Linux, uv-managed non-package Python project. pyproject.toml requires Python >=3.12 and uv >=0.13.1; .python-version selects 3.12. Review pyproject.toml and uv.lock together for dependency changes.
- Runtime: duckdb, markdown, pandas, numpy, pyarrow, scipy, scikit-learn (sklearn), ruptures, matplotlib, seaborn, plotly[express]. Dev group: nbconvert, jupyterlab, ipykernel, anywidget. No installed application package or build-system service.
- Use existing .venv/bin/python for data-free checks to avoid dependency synchronization. Serena's own interpreter is not the project interpreter.
- src/config/_base.py defines frozen AnalysisConfig(data_dir, output_dir, is_production); PROJECT_ROOT derives from that file, not cwd. Profiles do not read data/create directories, select via environment/machine detection, or enforce filesystem containment. No .env profile switch.
- src/config is not installed by uv sync. Launch from repo root with PYTHONPATH="$PWD/src" uv run --locked jupyter lab, or use docs/project/notebook_template.md's ancestor-search configuration cell in editor kernels. In private copies change both import to config.production and the existence check to production.py.
- The dataset randomization utility, setup/create_example_dataset.py, uses only Python standard-library argparse/csv/Decimal/pathlib/SystemRandom/hashlib/tempfile; tests in setup/tests use unittest and invented fixtures. It needs no extra dependencies.
- Other utilities: csv_to_parquet.py uses DuckDB; notebook_to_raw_python.py uses nbconvert; create_documentation_site.py uses Python-Markdown extra/toc with local preprocessing/link processing. Third-party imports follow argument parsing so --help is data-free.
- setup/initial_setup.sh is Bash; automated apt installs target Ubuntu/Debian/WSL. Existing tools can be reused on other Linux distributions; native Windows/macOS automation is not implemented.
- .gitattributes tracks CSV/Parquet through Git LFS, not notebooks. .githooks provides the private-path guard and LFS hooks; bootstrap sets executable permissions and repository-local core.hooksPath.
- Serena is separately installed. .serena/project.yml selects Python+Markdown LSP, REPL and ignore handling/production exclusions. Confirm active project on the exact MCP connection before memory/symbol writes.
- Phase 1 is a self-contained notebook with library-tagged code cells and embedded synthetic checks, not an installed module. Its older input contracts require alignment; details in `mem:core`.
- CI: .github/workflows/ci.yml uses ubuntu-24.04, project Python 3.12, uv 0.13.1, uv sync --locked (including default dev dependencies), and standard-library unittest discovery. Third-party actions are commit-pinned; checkout disables LFS downloads and persisted credentials. No pytest/linter/type-checker dependency was added.
