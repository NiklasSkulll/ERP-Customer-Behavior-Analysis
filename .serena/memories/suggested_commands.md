# Commands and operational traps (repository root)
- Contributor bootstrap: bash setup/initial_setup.sh. --check is read-only local status (exit 1 when incomplete); --yes approves recommended tool installs but stops for conflicting hooks; --no-color disables colour. Bootstrap changes hooks/local Git config, retrieves LFS and prepares the environment; do not run as routine verification.
- Dependencies: uv sync --locked. Intentional changes: uv add PACKAGE / uv add --dev PACKAGE, reviewing pyproject.toml and uv.lock together. Data-free consistency check: uv --no-cache lock --check --offline.
- Jupyter: PYTHONPATH="$PWD/src" uv run --locked jupyter lab. Select .venv/bin/python; editor kernels can instead use the notebook template's source-directory discovery.
- Data-free help: .venv/bin/python -B setup/csv_to_parquet.py --help; likewise setup/create_example_dataset.py, setup/notebook_to_raw_python.py and setup/create_documentation_site.py. Existing interpreter avoids incidental synchronization.
- Automated tests: .venv/bin/python -B -m unittest discover -s setup/tests -v. Covers dataset randomization, CSV-to-Parquet routing/round-trips/update failures, isolated docsite builds/navigation/lists, analysis/Jupyter imports, Tornado async operation and in-memory notebook HTML/Python exports. Dependencies must already be installed; no repository datasets or analysis execution are needed. This is not a full analysis-pipeline suite.
- CI runs the same discovery through uv run --locked python -B -m unittest discover -s setup/tests -v on PRs targeting main, pushes to main and workflow_dispatch. Python/notebook-cell syntax and bash -n setup/initial_setup.sh are separate steps. CI notebook syntax uses IPython TransformerManager then ast.parse to accommodate magics without executing them; see .github/workflows/ci.yml for the exact inline command.
- CSV converter: uv run --locked python setup/csv_to_parquet.py --folder {raw,interim,processed}. Reads immediate CSV files in the selected data/data-example stage; --prd selects private roots for user-run use. Writes sibling ZSTD Parquet, retains CSV, skips existing Parquet unless --update; missing/empty folders fail. Agent verification uses isolated invented fixtures only.
- Dataset randomization utility user command: .venv/bin/python -B setup/create_example_dataset.py --input-dir PATH --output-dir NEW_OR_EMPTY_PATH. Requires inputs already prepared with all four documented CSV filenames, column sets, consistent order headers and supported formats; no input profile autodetection or overwrite option. --delimiter accepts semicolon (default), comma, tab; --decimal-mark accepts period (default), comma. Output is always UTF-8 semicolon CSV with period decimals.
- Dataset randomization utility --min-amount/--max-amount are inclusive replacement magnitudes, default 1.00/100000.00. Explicit bounds accept exact cents from 0.01 through 1000000000000; minimum must not exceed maximum. Insufficient distinct replacements fail. Zeros/sign/missingness persist; full rows and join relationships persist, monetary trends do not. Transformed output retains the input dataset's provenance; access boundaries in `mem:core` still apply under an example path.
- Notebook export is USER-managed: uv run --locked python setup/notebook_to_raw_python.py --file RELATIVE.ipynb or --all-files. Mirrors go to src/raw-notebooks/<stem>_mirror.py with subfolders preserved. Agents inspect help only, never regenerate mirrors.
- Documentation user build: uv run --locked python setup/create_documentation_site.py; replaces docs/docsite/ via docs/docsiteTEMP/. IMPORTANT: repository-wide rglob precedes exclusion filtering, so it traverses protected directories. Agents build only in isolated copies of explicitly allowed Markdown/code or fully synthetic fixtures, never in the real checkout.
- Docsite links interpret local Markdown references as repository-root-relative. Converted sources link to generated HTML with queries/fragments preserved; other local targets link to GitHub main (blob files/tree folders ending /). Final known generated index/pages/headings stay in the current tab; external targets open new tabs. Ordinary document-relative links and GitHub-vs-Python-Markdown heading-ID differences remain limitations; verify actual anchors.
- Data-free source-notebook syntax check: parse code-cell sources from src/notebooks/001_f_phase_1.ipynb using json and ast.parse with .venv/bin/python -B; never execute notebook cells as onboarding. Notebook nbformat validation is also data-free. Legacy notebook schema caveat: `mem:core`.
- Serena: serena memories check audits memory references; inspect the report, not exit status alone. Run serena project index only after validating exclusions and with explicit need; no indexing during routine memory refresh.
