# Commands and operational traps (repository root)
- Contributor bootstrap: bash setup/initial_setup.sh; --check is read-only status (exit 1 when incomplete, not a lockfile/remote audit); --yes approves recommended setup/installations but stops for conflicting custom hooks; --no-color disables colors.
- Bootstrap activates existing .githooks locally, chmods hooks executable, runs git lfs install --local --skip-repo then git lfs pull, prepares Python from .python-version, and uv sync --locked --python VERSION. It confines uv to repo .venv and clears project/working-dir overrides; it does not install a pre-commit framework or Serena.
- Synchronize dependencies: uv sync --locked. Intentional dependency changes: uv add PACKAGE or uv add --dev PACKAGE; review/commit pyproject.toml and uv.lock together. Data-free consistency check: uv --no-cache lock --check --offline.
- Jupyter: PYTHONPATH="$PWD/src" uv run --locked jupyter lab. Read-only Python discovery: uv --no-cache python find --no-python-downloads 3.12; --no-cache avoids discovery writes to uv's normal cache.
- Data-free utility help: .venv/bin/python -B setup/csv_to_parquet.py --help; same for setup/notebook_to_raw_python.py and setup/create_documentation_site.py. Existing interpreter avoids incidental synchronization.
- CSV utility requires --folder {raw,interim,processed}; reads immediate CSV files under data/data-example/<folder>/, or the corresponding data/data-prd/<folder>/ with --prd. It is nonrecursive, retains CSV originals, writes sibling ZSTD Parquet and skips existing output unless --update. Missing/empty folders fail. Verify only in isolated fully synthetic fixtures; never execute against real production roots.
- Notebook export is USER-managed: uv run --locked python setup/notebook_to_raw_python.py --file RELATIVE.ipynb or --all-files. Mirrors go to src/raw-notebooks/<stem>_mirror.py with subfolders preserved. Agents may inspect help, never regenerate mirrors.
- Documentation build (user command): uv run --locked python setup/create_documentation_site.py; replaces docs/docsite/ via docs/docsiteTEMP/. Styles live in SITE_CSS. IMPORTANT: discovery uses repository-wide rglob before filtering excluded paths; exclusions do not prune traversal. Under the no-inspection boundary, build only in an isolated copy of explicitly allowed public Markdown sources or fully synthetic fixtures, then copy generated artifacts back. Links are interpreted as repo-root-relative: converted Markdown targets use HTML with preserved queries/fragments; other local targets use GitHub main (blob for files, tree for paths ending in /). Final HTML link targets are set by set_link_targets: navigation, cross-page and external links use _blank with noopener noreferrer; same-page heading fragments use _self. This also covers raw HTML anchors and index/back links without changing hrefs. Ordinary document-relative links remain a known limitation. Python-Markdown heading IDs also differ from some GitHub-style TOC fragments (notably phase headings and duplicate headings); verify generated anchors rather than assuming source TOCs work.
- Serena indexing: serena project index only after validating exclusions; do not trigger during routine memory refresh. Memory reference audit: serena memories check (inspect its report, not exit code alone).

- Data-free source-notebook syntax check (no cell execution): `.venv/bin/python -B -c 'import ast,json; from pathlib import Path; nb=json.loads(Path("src/notebooks/001_f_phase_1.ipynb").read_text()); [ast.parse("".join(c["source"])) for c in nb["cells"] if c["cell_type"] == "code"]'`. Notebook schema validation can additionally use nbformat when available in the project environment.
- The Phase 1 notebook is the assessment entrypoint, not a utility CLI. Review its explicit settings before a user-managed run; changing CONFIG switches roots, while SOURCES/parsing settings must match the declared extracts. Do not use Run All as onboarding or memory-refresh verification.
