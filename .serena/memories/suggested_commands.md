# Commands and operational traps (repository root)
- Contributor bootstrap: bash setup/initial_setup.sh; --check is read-only status (exit 1 when incomplete, not a lockfile/remote audit); --yes approves recommended setup/installations but stops for conflicting custom hooks; --no-color disables colors.
- Bootstrap activates existing .githooks locally, chmods hooks executable, runs git lfs install --local --skip-repo then git lfs pull, prepares Python from .python-version, and uv sync --locked --python VERSION. It confines uv to repo .venv and clears project/working-dir overrides; it does not install a pre-commit framework or Serena.
- Synchronize dependencies: uv sync --locked. Intentional dependency changes: uv add PACKAGE or uv add --dev PACKAGE; review/commit pyproject.toml and uv.lock together. Data-free consistency check: uv --no-cache lock --check --offline.
- Jupyter: PYTHONPATH="$PWD/src" uv run --locked jupyter lab. Read-only Python discovery: uv --no-cache python find --no-python-downloads 3.12; --no-cache avoids discovery writes to uv's normal cache.
- Data-free utility help: .venv/bin/python -B setup/csv_to_parquet.py --help; same for setup/notebook_to_raw_python.py and setup/create_documentation_site.py. Existing interpreter avoids incidental synchronization.
- CSV utility scans immediate data/data-example/*.csv, writes sibling ZSTD Parquet, skips existing output unless --update. Schema docs use data/data-example/raw/: mismatch remains. Never use --prd as an agent; confirm fully synthetic inputs before execution.
- Notebook export is USER-managed: uv run --locked python setup/notebook_to_raw_python.py --file RELATIVE.ipynb or --all-files. Mirrors go to src/raw-notebooks/<stem>_mirror.py with subfolders preserved. Agents may inspect help, never regenerate mirrors.
- Documentation build (user command): uv run --locked python setup/create_documentation_site.py; replaces docs/docsite/ via docs/docsiteTEMP/. Styles live in SITE_CSS. IMPORTANT: discovery uses repository-wide rglob before filtering excluded paths; exclusions do not prune traversal. Under the no-inspection boundary, use copied script + synthetic temporary docs rather than a real-checkout rebuild. Links are interpreted as repo-root-relative, so ordinary document-relative links can still be rewritten incorrectly.
- Serena indexing: serena project index only after validating exclusions; do not trigger during routine memory refresh. Memory reference audit: serena memories check (inspect its report, not exit code alone).
