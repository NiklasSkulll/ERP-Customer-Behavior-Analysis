- Follow repository defaults subject to explicit user/session overrides. Preserve unrelated changes and staged state; do not commit/push unless requested. Report only checks actually run; do not broaden into notebook execution without a task-specific reason.

Generated HTML is not authoritative source evidence.

Existing Phase 1 has library-tagged cells and implementation_sha256 metadata; inspect their meaning before using an isolated verification harness/updating code fingerprints.
